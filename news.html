Autarkeia OS 1.1 "Teleios" released

2026-11-25

The system built by the tinycc-os-kernel project now has a name, Autarkeia OS (Greek for self-sufficiency), and 1.1 is its first release with ISO images to download, for x86_64 and i386. Everything in them, from the Linux 7.3 kernel to the X server and the NetSurf browser, is compiled by a patched Tiny C Compiler, with no GCC and no binutils.

  • The name in /etc/os-release, the boot banner, the GRUB menu, the xdm login and the logo.
  • A package list for every release (scripts/package-list.sh): 68 components, 162 tcc patches.
  • NetSurf: scrollWidth and scrollHeight count content that overflows.

Version 1.1 contains everything in 1.0 "Teleios" (2026-11-24): i386 next to x86_64, both self-hosting; the kernel built from vanilla Linux with no kernel patches; the graphical session (TinyX with Composite, JWM, xdm, mlterm, xedit); drivers for real hardware in seven groups; and NetSurf 3.11 with JavaScript on QuickJS.
